# RAG_system

Локальное веб-приложение для вопросов по PDF: загружай документы и общайся
с RAG-ассистентом в браузере. FastAPI обрабатывает запросы, Chroma хранит
фрагменты, Gemini формирует ответы, Cohere переранжирует результаты поиска.

## Запуск

Нужен Python 3.12 или новее. В существующем окружении проекта установи
зависимость загрузки файлов:

```powershell
.\venv\Scripts\python.exe -m pip install python-multipart
```

Полный список зависимостей пока не зафиксирован, поэтому установка проекта
с нуля остаётся отдельной задачей.

В локальном `.env` задай `GOOGLE_API_KEY` и `COHERE_API_KEY`.
Из корня проекта запусти сервер:

```powershell
& .\venv\Scripts\Activate.ps1
python -m uvicorn api:app --reload
```

Открой **http://127.0.0.1:8000/**. Для веб-приложения достаточно этого процесса.
Старый Telegram-код остаётся в репозитории, но запускать его не требуется.

## Как пользоваться

- Загрузи PDF до 20 МБ с извлекаемым текстом. OCR для сканов не реализован.
- После успешной индексации задай вопрос в чате.
- Файлы получают уникальные имена и сохраняются в `data/<user_id>/`.
- При ошибке индексации выполняется откат фрагментов только новой загрузки.
- История последних 10 сообщений и идентификатор локального профиля
  сохраняются в браузере.

Прототип работает без регистрации и авторизации. `user_id` служит фильтром
документов локального профиля, а не защитой от других клиентов. Запускай
сервер на стандартном адресе `127.0.0.1` для локального использования.

## API

- `GET /` — веб-интерфейс.
- `POST /upload` — multipart-поля `file` (PDF) и `user_id` (положительное
  целое число). Успех: `{"chunks": 12}`.
- `POST /ask` — JSON с непустым `input`, положительным целочисленным
  `user_id` и необязательным `chat_history`. История содержит объекты с
  `role` (`user`, `ai`, `assistant`) и непустым `content`.
  Успех: `{"answer": "..."}`.

Некорректный запрос возвращает 422, ошибка обработки PDF — 400,
слишком большой файл — 413, ошибка внешнего сервиса — 502.

## Проверки

```powershell
.\venv\Scripts\python.exe -m pip install pytest
.\venv\Scripts\python.exe -m pytest
```

Тесты используют заглушки внешних сервисов и временные файлы,
не обращаются к платным API и не изменяют локальную базу `db/`.
Реальные ответы Gemini/Cohere требуют отдельной проверки с ключами.
